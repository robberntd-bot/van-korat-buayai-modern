# รถตู้พรทวีชัย โคราช - บัวใหญ่ (Modern Redesign)

เวอร์ชันที่ออกแบบใหม่สำหรับเว็บไซต์รถตู้พรทวีชัย โคราช-บัวใหญ่

**เก็บข้อมูลเดิมทั้งหมด:**
- บริษัท พรทวีชัยราชสีมา จำกัด
- ราคา 110 บาท ทั้งสาย
- 13 ที่นั่ง
- ตารางเวลา 3 / 3+ / 4 / 4+
- แผนที่จุดขึ้นรถท่าโคราช และบัวใหญ่

เปิด GitHub Pages ได้ที่ Settings → Pages → Deploy from branch `main`
